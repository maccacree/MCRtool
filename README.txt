MCRtool Portable 0.2 — Windows 10/11

БЫСТРЫЙ СТАРТ
Распакуйте весь архив в записываемую папку или на USB-флешку.
В обычной Windows запустите MCRtool.exe. Установка не требуется.
В комплекте уже есть собранный GUI EXE и нативный Recovery EXE.
Основной GUI использует .NET Framework 4.5+, Recovery — без .NET/PowerShell.
Основной сценарий выпуска: Windows 10/11 x64 и WinRE x64.
Оба EXE не подписаны цифровым сертификатом.

ЧТО ДОБАВЛЕНО
1. Поиск файлов по имени с индексом в оперативной памяти.
   Выберите корневую папку и нажмите «Построить индекс». После обхода
   вводите часть имени: фильтрация не учитывает регистр. Это собственный
   поиск MCRtool, не интеграция Everything и не индекс NTFS MFT/USN.
   Первый обход может быть долгим. Индекс: до 250 000 файлов; список:
   до 5 000 строк; CSV содержит ВСЕ совпадения текущего индекса.
   Есть остановка, открытие папки с выделением файла, SHA-256, экспорт CSV.
   Ссылки/junction и недоступные каталоги пропускаются с подсчётом.
   Изменения файлов появятся после повторного построения индекса.
2. Планировщик: список, включая скрытые задания; фильтр по пути;
   просмотр XML, экспорт XML, включение/отключение одного задания.
   Перед переключением сохраняется .mcrtask с определением и состоянием.
   «Восстановить состояние» возвращает прежнее Enabled. Если определение
   задания изменилось, операция отменяется. Это не восстановление удалённых
   заданий и не импорт XML. Редактирование расписания и действий доступно
   через кнопку «Открыть системный редактор».
   Отключение не останавливает уже запущенный процесс задания.
   Для изменения системных заданий может понадобиться запуск от администратора.
3. MCRtool-Recovery-x64.exe — отдельная консольная утилита для WinRE/WinPE.
   Показывает тома, ищет файлы, перечисляет файлы офлайн-заданий,
   исправляет выбранные пользовательские ограничения и прокси,
   восстанавливает одно значение из своей копии.

ИСПРАВЛЕНИЯ ОСНОВНОГО ОКНА
Снятие запретов Task Manager, Registry Editor, CMD, Control Panel, Run.
Отключение ручного прокси и удаление PAC URL по выбору.
Просмотр Run/RunOnce, папок Startup и hosts; экспорт текстового отчёта.
Флажки изначально сняты. Перед записью сохраняется XML-копия выбранных
значений. Нельзя сохранить копию — исправление не начинается.
Резервные копии и копии заданий: MCRtool-data рядом с EXE.
При переносе сохраняйте эту папку вместе с программой.
GUI изменяет HKCU запустившего пользователя; запуск под другой учётной
записью администратора переключает область пользовательских исправлений.
Машинные политики HKLM не изменяются.

КОНСОЛЬ ВОССТАНОВЛЕНИЯ — ПРИМЕР
Заранее распакуйте архив на USB. В WinRE откройте «Командная строка».
Буквы ниже — ПРИМЕРЫ: E: — USB с MCRtool, D: — установленная Windows.
Сначала выполните:

  E:\MCRtool\MCRtool-Recovery-x64.exe drives
  E:\MCRtool\MCRtool-Recovery-x64.exe scan D:\Windows
  E:\MCRtool\MCRtool-Recovery-x64.exe find D:\Users invoice
  E:\MCRtool\MCRtool-Recovery-x64.exe tasks D:\Windows

Имя папки профиля можно посмотреть командой dir D:\Users.
Пример снятия запрета Диспетчера задач для Alice:

  E:\MCRtool\MCRtool-Recovery-x64.exe repair-user D:\Windows D:\Users\Alice\NTUSER.DAT taskmgr

Проверьте показанные пути и введите YES. Доступные идентификаторы:
  taskmgr, regedit, cmd, controlpanel, run, proxy, pac
За один вызов изменяется только один выбранный параметр.
Перед изменением сохраняются value.mcrb (один параметр) и
NTUSER-before.hiv (полная аварийная копия пользовательского реестра).
Полный путь папки с копиями печатается в консоли.
Для восстановления выбранного значения:

  E:\MCRtool\MCRtool-Recovery-x64.exe restore-user D:\Windows D:\Users\Alice\NTUSER.DAT "E:\MCRtool\MCRtool-data\recovery-...\value.mcrb"

Замените recovery-... на настоящий путь, напечатанный утилитой.
Восстановление сначала также сохраняет текущее состояние.
Путь NTUSER.DAT должен совпадать с записанным в value.mcrb, включая букву
тома: между сеансами WinRE буквы могут измениться. Не переименовывайте
копию NTUSER-before.hiv в NTUSER.DAT и не заменяйте ею профиль без необходимости:
эта аварийная копия содержит весь профиль реестра, включая другие настройки.
Ключ профиля выгружается после операции. При ошибке выгрузки программа
печатает точную команду reg unload; выполните её перед перезагрузкой.
Команды repair-user/restore-user работают только при обнаружении WinRE/WinPE.
Самостоятельный запуск MCRtool-Recovery.cmd без аргументов показывает справку.
Справка консоли на английском; пути Unicode поддерживаются.
Вывод можно перенаправить в файл через > report.txt (UTF-8).

ОГРАНИЧЕНИЯ RECOVERY
Native EXE имеет архитектуру x64, не ARM64/x86.
Проверено наличие файлов Windows, но правильную установку и профиль
выбирает пользователь. Данные BitLocker доступны только после разблокировки.
В этой версии Windows и профиль должны находиться на одном томе.
Поддерживаются локальные пути короче 260 символов.
Офлайн-планировщик: только список файлов; изменение выполняйте в Windows.
Служба Scheduler и её TaskCache офлайн не редактируются.
На USB должна быть доступна запись для резервных копий.
Коды завершения: 0 — успех, 2 — ошибка/неполный обход, 3 — отмена.
При загрузке офлайн-реестра Windows может воспроизвести его журнал транзакций.

ПРОВЕРКА И СБОРКА
Сборка обоих EXE прошла без предупреждений. Восемь автоматических тестов
прошли: сравнение XML, блокировка DTD, CSV, сериализация копий.
Проверены PE-формат и импорты Recovery: ADVAPI32, KERNEL32, msvcrt.
Реальная работа GUI, Task Scheduler, реестра и WinRE не проверялась на Windows.
Порядок испытаний на VM: TESTS.md. Сначала используйте тестовую VM со снимком.

Исходники включены. build.cmd пересобирает GUI через штатный csc.exe
.NET Framework 4. build-recovery.cmd пересобирает консольную часть при наличии
MinGW-w64 x64 GCC. Готовые EXE позволяют обойтись без пересборки.
Исходники автоматических тестов: tests/Tests.cs; запуск — tests/run-tests.cmd.
Контрольные суммы комплекта: SHA256SUMS.txt.

MCRtool исправляет выбранные последствия; обнаружение и удаление активного
вредоносного ПО не реализовано. Корпоративные политики и легитимные настройки
могут выглядеть так же. Программа не отключает антивирус и не запускает задания.
Резервные копии профиля и отчёты могут содержать личные данные; храните их у себя.
